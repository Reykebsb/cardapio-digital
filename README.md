# 🍔 Cardápio Digital

Sistema white-label de cardápio digital e gestão de pedidos para estabelecimentos de alimentação (hamburguerias, pizzarias, creperias, marmitarias, food trucks e mais).

## ✨ Funcionalidades

- 📱 Cardápio digital responsivo (mobile-first)
- 🛒 Carrinho de compras com adicionais e observações
- 📲 Envio automático de pedidos via WhatsApp
- 📊 Painel administrativo com pedidos em tempo real
- 🎨 Tema personalizável por estabelecimento (cores, logo, dados)
- 💰 Zero taxa por venda (diferente de iFood/Rappi)

## 🛠️ Stack

- **Frontend:** React + TypeScript + Vite + Tailwind CSS v4 + shadcn/ui
- **Backend:** Supabase (PostgreSQL + Auth + RLS + Realtime)
- **Deploy:** Vercel
- **Estado:** Zustand + TanStack Query

## 🚀 Como funciona

Cada estabelecimento recebe um link personalizado:
`cardapio-digital.vercel.app/nome-do-estabelecimento`

O cliente acessa pelo celular, monta o pedido e envia direto para o WhatsApp do dono — sem intermediários, sem taxas.
